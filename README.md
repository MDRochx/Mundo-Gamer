- Trabalho de HTML/CSS - Mundo Gamer 🎮

Projeto simples de um site sobre jogos eletrônicos desenvolvido para uma atividade prática da faculdade.

📝 O que tem no site:
Páginas: Menu para navegar entre Início, Consoles e PC Gaming.
Elementos: Uso de tabelas (linha do tempo), listas de vantagens, links para sites de notícias e imagens.
Visual: Tema escuro com detalhes em verde e alguns efeitos simples ao passar o mouse nos botões e links.
Organização: Arquivos HTML na raiz e pastas separadas para imagens (`imgs/`) e estilo (`css/`).
